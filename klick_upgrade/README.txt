# Klick — Loja de aplicativos (versão melhorada)

Projeto front-end feito com HTML, CSS e JavaScript puro.

## Melhorias desta versão
- Cards da página inicial com imagens grandes, no estilo de uma loja de aplicativos.
- Imagens distribuídas aleatoriamente a cada carregamento.
- Hero da página inicial com imagem aleatória.
- Carrinho funcional com adicionar, remover, aumentar e diminuir quantidade.
- Contagem de itens do carrinho atualizada no cabeçalho.
- Total do carrinho calculado automaticamente.
- Botão para limpar o carrinho.
- Checkout exige login antes de concluir.
- Compras concluídas vão para a biblioteca.
- Busca, filtros e ordenação funcionando.
- Categorias funcionando.
- Detalhes dos aplicativos funcionando.
- Login/logout e perfil funcionando em modo demonstração.
- Publicação de aplicativo funcionando em modo demonstração.
- Persistência de carrinho, login e biblioteca com localStorage.
- Layout responsivo para computador e celular.
- Tratamento básico para imagens que falharem ao carregar.

## Como executar
1. Extraia o ZIP.
2. Abra `index.html` no navegador.
3. Para desenvolvimento, recomenda-se usar o Live Server do VS Code.

## Observação
As imagens dos cards usam URLs externas do Unsplash. O login, as compras e a publicação são demonstrações locais; não existe pagamento real, servidor ou banco de dados.
